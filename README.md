## 🚀 نصب در ۵ دقیقه

1. همه‌ی فایل‌های این ریپو رو در یه ریپوی GitHub آپلود کن (یا Fork بزن).
2. در [Railway](https://railway.com): **New Project ← Deploy from GitHub repo** و همین ریپو رو انتخاب کن.
3. **Settings ← Networking ← Generate Domain** و پورت رو دقیقاً **`8080`** بذار.
4. **Volume** اضافه کن با مسیر **`/var/lib/pasarguard`**. بدون این، با هر Deploy کاربرها پاک میشن.
5. **Settings ← Region** رو بذار روی **EU West (Amsterdam)**. برای ایران کمترین پینگ رو داره.
6. یک بار **Redeploy** کن تا دامنه شناسایی بشه. تمام 🎉
